# 📝 CLI Word Counter

Analyze your text instantly! A precise Command Line Interface (CLI) tool that counts the number of words in any sentence or paragraph you provide.

## 🚀 Features
- **Sentence Analysis**: Simply paste or type your text to get an instant count.
- **Whitespace Handling**: Automatically trims and splits text for accuracy.
- **Visual Word List**: Displays the breakdown of identified words.
- **Polished Output**: Elegant formatting with banners and colors.

## 🛠️ Technologies
- **TypeScript**: For clean and manageable source code.
- **Node.js**: Powering the CLI execution.
- **Inquirer**: For capturing user input sentences.
- **Chalk**: For aesthetic terminal styling.
- **Node-Banner**: To give the tool a professional look.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node word-counter/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx word-counter/index.ts
```
