# ⌛ CLI Countdown Timer

Never lose track of time! A functional and precise Command Line Interface (CLI) countdown timer designed for time-sensitive tasks and productivity.

## 🚀 Features (Planned)
- **Custom Time Entry**: Set timers for specific durations (seconds, minutes, or hours).
- **Real-Time Updates**: Watch the seconds tick down directly in your terminal.
- **Completion Alerts**: Get notified with stylized messages when time is up.
- **Pause & Resume**: (Coming Soon) Control your timer with interactive commands.

## 🛠️ Technologies
- **TypeScript**: Ensuring precise timing logic.
- **Node.js**: The cross-platform CLI runtime.
- **Inquirer**: For capturing user-defined durations.
- **Chalk**: For a clear and visual time display.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node countdown-timer/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx countdown-timer/index.ts
```


## ▶️ Run Without Installation

Try it directly in your terminal — no cloning or setup needed:

```bash
npx @muhammed_suhaib/countdown-timer
```
or
```bash
pnpm dlx @muhammed_suhaib/countdown-timer
```
