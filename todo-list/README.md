# ✅ CLI Todo List

Organize your day efficiently! A simple and effective Command Line Interface (CLI) todo list application to keep track of your tasks.

## 🚀 Features
- **Add Tasks**: Quickly add new items to your todo list.
- **Continuous Entry**: Option to add multiple tasks in a single session.
- **Live List View**: Displays your updated list after each entry.
- **User-Friendly Interface**: Simple prompts for a seamless experience.

## 🛠️ Technologies
- **TypeScript**: For a reliable development experience.
- **Node.js**: The cross-platform runtime.
- **Inquirer**: For interactive task management.
- **Chalk**: For vibrant and clear terminal output.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node todo-list/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx todo-list/index.ts
```


## ▶️ Run Without Installation

Try it directly in your terminal — no cloning or setup needed:

```bash
npx @muhammed_suhaib/todo-list
```
or
```bash
pnpm dlx @muhammed_suhaib/todo-list
```
