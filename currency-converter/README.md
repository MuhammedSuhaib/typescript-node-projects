# 💱 CLI Currency Converter

Convert your money on the go! A powerful CLI tool to convert amounts between different global currencies using real-time-like conversion rates.

## 🚀 Features
- **Multi-Currency Support**: USD, EUR, GBP, PKR, and INR.
- **Accurate Conversions**: Uses a base currency (USD) for reliable calculations.
- **Dynamic Selection**: Choose "From" and "To" currencies from an interactive list.
- **Clean Interface**: Visual clarity with stylized results and banners.

## 🛠️ Technologies
- **TypeScript**: Ensuring precise logic and type safety.
- **Node.js**: The foundational runtime environment.
- **Inquirer**: For smooth selection of currencies and amounts.
- **Chalk**: For highlighting conversion results.
- **Node-Banner**: Displays a professional header.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node currency-converter/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx currency-converter/index.ts
```
