# ⏱️ CLI Fast Quiz

Test your knowledge at lightning speed! An interactive Command Line Interface (CLI) quiz application designed to challenge your understanding of TypeScript and common CLI commands.

## 🚀 Features
- **Educational Content**: Questions focused on TypeScript fundamentals and terminal basics.
- **Scoring System**: Earn points for every correct answer and see your final tally at the end.
- **Instant Feedback**: Immediate notification for correct and incorrect answers.
- **Dynamic Result Display**: Features a rainbow-colored final score animation.

## 🛠️ Technologies
- **TypeScript**: For a type-safe and structured codebase.
- **Node.js**: The platform for CLI execution.
- **Inquirer**: Managing the quiz flow and user selections.
- **Chalk**: For visually distinct success and error messages.
- **Node-Banner**: Displays a professional "Fast Quiz" banner.
- **Chalk-Animation**: For a celebratory final score presentation.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node quiz/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx quiz/index.ts
```


## ▶️ Run Without Installation

Try it directly in your terminal — no cloning or setup needed:

```bash
npx @muhammed_suhaib/quiz
```
or
```bash
pnpm dlx @muhammed_suhaib/quiz
```
