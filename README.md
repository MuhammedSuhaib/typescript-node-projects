## 📖 About

These projects were designed by **Sir Zia Khan** (Panaverse) to strengthen TypeScript + Node.js skills, and assigned under **Sir Ameen Alam** as part of the **GIAIC Quarter-1** curriculum.

Live support was provided during **Ramadan Coding Nights** (March–April 2024) — a series hosted by the Governor Sindh Initiative for GenAI, Web3.0 and Metaverse.

**Session hosts:** Zia Khan · Ameen Alam · Muhammad Osama · Mubashir Ali · Muhammad Bilal Khan · Hamzah Syed · Manal Rana · Okasha · Asharib Ali
**Technical support:** Sir Imran Ali
