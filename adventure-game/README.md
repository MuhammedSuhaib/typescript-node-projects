# ⚔️ CLI Adventure Game: "The Dungeon"
> "I watched a Java tutorial on creating an adventure game and made it in TypeScript on August 31, 2024, following the directions from Sir Zia's repository, all in just one day."

Embark on a perilous journey! A thrilling text-based RPG where you navigate through a dangerous dungeon, battle fierce enemies, and survive against all odds.

## 🚀 Features
- **Diverse Enemies**: Battle against Zombies, Assassins, Warriors, and Skeletons.
- **Dynamic Combat**: Strategy-based attack system with randomized damage dealing and receiving.
- **Survival Mechanics**: Manage your Health Points (HP) and use Health Potions to stay alive.
- **Loot System**: Defeated enemies have a chance to drop health potions.
- **Strategic Choices**: Decide whether to attack, heal, or run away from a fight.

## 🛠️ Technologies
- **TypeScript**: Powering the game logic and state management.
- **Node.js**: The execution runtime for the CLI adventure.
- **Inquirer**: Handling interactive player decisions.
- **Chalk**: Providing immersive and colorful terminal feedback.
- **Node-Banner**: Welcomes players with a thematic "Dungeon" banner.

## 📖 How to Run
Run the project directly from the root directory using Node.js:

```bash
node adventure-game/index.ts
```

Or using `tsx`:

```bash
pnpm dlx tsx adventure-game/index.ts
```
